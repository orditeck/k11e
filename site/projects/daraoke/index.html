What it does

A native macOS player for an MP3/CDG ZIP, with key adjustment and lyric timing controls. The source and early macOS releases are public.

Here now, not a roadmap

  • Open an MP3/CDG ZIP and play it without a network service.
  • Adjust the key without changing tempo, and shift lyric timing.

Version 0.1.2 is available for Apple Silicon and Intel, on macOS 14 or later. Builds are ad-hoc signed, not Developer ID signed or notarized. macOS may ask you to approve the first launch.

Read the installation notes

Still on the roadmap

Library management, karaoke-night queues and a separate lyric display are not features of this version. An early release can be useful without pretending to be finished.
