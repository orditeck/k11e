Ce que fait l'app

Un lecteur macOS natif pour les ZIP MP3/CDG, avec réglage de la tonalité et du décalage des paroles. Le code source et les premières versions macOS sont publics.

Ce qui existe aujourd'hui

  • Ouvrir un ZIP MP3/CDG et le lire sans service réseau.
  • Régler la tonalité sans changer le tempo et ajuster le décalage des paroles.

La version 0.1.2 est disponible pour Apple Silicon et Intel, sur macOS 14 et plus. Les apps sont signées ad hoc, sans signature Developer ID ni notarisation. macOS peut demander une approbation au premier lancement.
